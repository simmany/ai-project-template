# 3단계. 참고 자료를 input 폴더에 넣기

2단계의 초안은 어느 회사에나 맞을 법한 내용이었을 것입니다. 에이전트가 우리 사정을 모르기 때문입니다. 에이전트가 알아야 하는 자료를 `input/` 폴더에 넣어 줍니다.

## 따라 하기

실습에서는 고객사의 교육 요청서 하나를 자료로 씁니다. 아래 글을 통째로 복사해 에이전트에게 보냅니다. 교육 요청서를 `input/`에 파일로 저장하고, 그 자료로 제안서를 다시 만들게 하는 요청입니다. 업무 에이전트에서 새 대화로 시작한다면 맨 앞에 'AGENTS.md를 먼저 읽고,'를 붙입니다.

```
아래는 고객사에서 받은 교육 요청서야. input/교육요청서.md로 저장하고, 이 자료를 바탕으로 제안서를 다시 만들어줘.

교육 요청서 (실습용 예시)

- 요청 회사: 가람물류 (가상의 회사)
- 요청 부서: 인재개발팀
- 대상: 2026년 하반기 신입 사원 24명 (비개발 직군)
- 목적: 입사 첫 달 안에 업무용 AI 에이전트를 스스로 쓸 수 있게 한다
- 기간: 3일, 하루 6시간
- 장소: 본사 교육장 (개인 노트북 지참)
- 예산: 1,200만 원 이내
- 꼭 들어갈 내용: 폴더와 자료 준비, 실제 업무 문서로 하는 실습, 보안 유의 사항
- 결정하는 사람: 인재개발팀장
```

내 업무에 쓸 때는 가지고 있는 파일을 `input/` 폴더에 직접 넣습니다. 요청 메일, 회의 메모, 기존 문서, 데이터 파일을 탐색기(Windows)나 Finder(Mac)에서 `input` 폴더로 끌어다 놓고 이렇게 보냅니다.

```
input/에 넣은 자료를 바탕으로 다시 만들어줘.
```

## 확인하기

- `input/`에 `교육요청서.md`가 생겼습니다.
- `output/`에 `v02`가 붙은 새 파일이 생겼고, `v01`은 그대로 있습니다.
- 새 초안에 교육 요청서의 조건(24명, 3일, 1,200만 원 이내)이 들어 있습니다.

## 무엇을 넣나요

- 업무 배경, 요구사항, 참고 문서, 데이터. PDF, 워드, 엑셀, 이미지 파일도 넣을 수 있습니다. 읽지 못하는 형식이면 에이전트가 알려 줍니다.
- 비밀번호나 주민등록번호 같은 민감한 정보는 넣지 않습니다. 손님의 이름과 연락처처럼 이번 작업에 꼭 필요하지 않은 개인정보는 가린 사본을 넣습니다.
- 회사 자료는 회사의 AI 사용 기준을 먼저 확인합니다. 에이전트는 열어 준 폴더에서 일하지만, 읽은 내용은 그 AI 에이전트를 운영하는 회사의 서버에서 처리됩니다.
- 자료가 많아지면 `input/README-TEMPLATE.md`를 복사해 `README.md`로 이름을 바꾸고, 맨 위의 안내와 예시 줄을 지운 뒤 자료 목록을 적어 둡니다. 에이전트에게 목록을 만들어 달라고 해도 됩니다. 목록이 없어도 에이전트는 파일 이름을 보고 골라 읽습니다.

## 왜 폴더에 넣나요

- 대화창에만 붙여 넣은 자료는 그 대화에서만 쓰입니다. `input/`에 넣은 자료는 다음 대화에서도, 다른 에이전트에게도 그대로 남습니다.
- 에이전트는 `input/`을 전부 읽지 않고 이번 작업에 필요한 파일만 골라 읽습니다. 그래서 자료를 넉넉히 넣어 두어도 됩니다.
