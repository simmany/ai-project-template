# 막혔을 때

## 폴더를 열 때 (1단계)

- 데스크톱 앱이 없습니다: 웹 브라우저로는 내 컴퓨터의 폴더를 쓰지 못합니다. 1단계에 적힌 주소에서 앱을 받아 설치합니다.
- Work나 Cowork가 보이지 않습니다: 앱을 최신 버전으로 올리고, 쓰는 요금제에 그 기능이 들어 있는지 봅니다. Claude는 '채팅'(Chat)과 Cowork를 고르는 자리가 없는 새 화면일 수 있습니다. 그때는 그대로 진행합니다.
- 폴더를 여는 자리를 찾지 못하겠습니다: 화면에서 '폴더', '프로젝트'가 들어간 이름을 찾습니다. 1단계에 적힌 이름과 다르면 1단계 맨 아래의 공식 안내를 봅니다.
- ChatGPT Work나 Codex 앱의 '작업 위치'가 '클라우드'로 돼 있습니다: 입력창에서 '이 컴퓨터'로 바꿉니다.
- 에이전트가 `AGENTS.md`를 찾지 못하거나 폴더의 이름들을 말하지 못합니다: 한 겹 바깥 폴더를 열었을 수 있습니다. `AGENTS.md`가 바로 보이는 폴더를 다시 엽니다. Windows에서 압축을 풀면 같은 이름의 폴더가 한 겹 더 생기곤 합니다.

## 파일을 열 때

- `.md` 파일이 열리지 않습니다: 글자만 든 파일입니다. Windows는 메모장, Mac은 텍스트 편집기로 엽니다. 파일을 오른쪽 버튼으로 눌러 여는 프로그램을 고릅니다. 에이전트에게 "그 파일 내용을 보여줘"라고 해도 됩니다.
- `.gitkeep`이라는 파일이 보입니다: 빈 폴더를 남겨 두려고 넣은 빈 파일입니다. 그대로 둡니다.
- `help`, `README.md`, `LICENSE`를 지워도 되나요: 됩니다. 템플릿의 안내와 라이선스이고, 일하는 데는 쓰이지 않습니다. 이 폴더를 다른 사람에게 다시 나눠 줄 때는 `LICENSE`를 남겨 둡니다.

## 요청과 기록

- `workflow/`에 기록이 남지 않습니다: 업무 에이전트(ChatGPT Work, Claude Cowork)에서 새 대화의 첫 말에 'AGENTS.md를 먼저 읽고,'를 붙였는지 봅니다. 빠뜨렸다면 "AGENTS.md를 읽고, 방금 한 일을 그 규칙대로 기록해줘."라고 보냅니다. 코딩 에이전트에서 기록이 남지 않을 때도 같은 말을 보냅니다. 처리 결과는 있는데 요청 사항에 요청이 빠졌을 때도 같은 대화에서 이 말을 보냅니다.
- 에이전트가 되묻기만 하고 멈춥니다: 아는 만큼 답합니다. 정해진 것이 없으면 "네가 정해서 진행해줘"라고 합니다.
- `rules/`나 `input/`에 저장하지 않고 어디에 둘지 묻습니다: 사람이 정하는 곳이라 확인하는 것입니다. "rules에 저장해줘"처럼 그 폴더에 저장하라고 답합니다.
- `rules/` 안에 폴더를 만들어 넣은 규칙을 지키지 않습니다: 규칙 파일은 `rules/` 바로 아래에 둡니다. 폴더 안에 둔 파일은 규칙 파일이나 요청에서 가리켜야 읽습니다("rules/회사 기준/문서 마무리.md도 지켜서 …").
- 권한을 묻습니다: 파일을 만들거나 웹을 찾아봐도 되는지 묻는 것입니다. 허락해야 작업이 끝까지 갑니다. 명령 실행이나 프로그램 설치를 물을 때는 아래 '코딩 요청'을 봅니다.
- 한국어가 아닌 말로 답합니다: "한국어로 답해줘"라고 보냅니다.

## 대화와 기억

- 새 대화에서 앞의 작업을 모릅니다: 7단계의 문장을 보냅니다. 업무 에이전트라면 'AGENTS.md를 먼저 읽고, status.md를 바탕으로 지금 상태와 다음 할 일을 알려줘.'입니다.
- 내 컴퓨터의 폴더에 닿지 못한다고 합니다: 데스크톱 앱이 켜져 있는지 봅니다. ChatGPT Work와 Codex 앱은 '작업 위치'가 '이 컴퓨터'인지도 봅니다.
- 결과가 우리 사정과 맞지 않습니다: 자료가 부족하면 `input/`에 더 넣고(3단계), 기준이 없으면 `rules/`에 둡니다(4단계).

## 코딩 요청 (6단계)

- 명령을 실행해도 되는지 묻습니다: 만든 것을 직접 실행해 확인하려는 것입니다. 허락합니다. 프로그램을 새로 설치해도 되는지 물을 때는 무엇을 왜 설치하는지 읽어 보고 정합니다.
- 스크립트를 실행하지 못했다고 합니다: AI 에이전트에 따라 명령을 실행하지 못하기도 하고, 실행에 필요한 프로그램(Python)이 컴퓨터에 없기도 합니다. 프로그램을 설치할지는 내가 정합니다. 설치하지 않는다면 스크립트 실습은 건너뜁니다. 화면을 만드는 실습은 Python 없이 됩니다.
- `index.html`을 더블클릭했는데 화면 대신 코드 글자가 보입니다: 편집기로 열린 것입니다. 파일을 브라우저(Chrome, Edge, Safari) 창에 끌어다 놓습니다.
- 화면은 열리는데 값을 바꿔도 반응이 없거나 계산이 이상합니다: 본 대로 에이전트에게 말합니다. 예: "index.html을 열었는데 단가를 바꿔도 합계가 그대로야. 확인하고 고쳐줘."
- `codebase/`가 아닌 곳에 만들었거나 필요 이상으로 복잡하게 만들었습니다: "rules/coding.md의 기준대로 다시 해줘."라고 보냅니다.
- 코딩 기준이 내 방식과 다릅니다: 요청에 방법을 적으면 그 작업은 그 방법으로 합니다. 늘 그렇게 하려면 `rules/coding.md`를 고칩니다.
- 인증키나 비밀번호가 필요하다고 합니다: 대화창에 붙여 넣지 않습니다. 6단계의 '내 업무에 쓸 때'를 봅니다.

## 개인 에이전트 (8단계)

- 개인 에이전트가 등록이 분명하지 않다고 하거나, 맡기기로 바꿨는데 권한 밖이라고 합니다: `PERSONAL-AGENT.md`의 권한 줄에서 콜론(:) 뒤에 `읽기(Read-only)`나 `맡기기(Delegate)` 가운데 하나만 적혀 있는지 봅니다. 8단계의 블록을 줄째로 옮겨 적으면 됩니다.
- 개인 에이전트로 맡긴 요청이 스크립트를 실행하는 자리에서 멈췄습니다: 8단계의 시작 명령은 파일을 만들고 고치는 일까지만 묻지 않고 허락합니다. 코드를 실행해야 하는 요청은 작업 에이전트의 대화창에서 직접 맡깁니다.

## 이 안내를 에이전트에게 물어보기

폴더를 연 뒤에는 막힌 곳을 에이전트에게 그대로 물어도 됩니다.

```
help 폴더의 안내를 읽고, 내가 지금 무엇을 하면 되는지 알려줘.
```
