# 근거 자료 분석 → 팩트 시트

사업계획서 평가위원은 수치마다 "출처가 어디인가"를 묻는다. 이 스킬의 목표는 집필가가 출처를 다시 찾지 않고 인용할 수 있고, 팩트체커가 같은 기준으로 대조할 수 있는 **팩트 시트**를 만드는 것이다.

## 1. 자료 목록 확인

1. 배정받은 파일을 모두 나열하고 형식(PDF·PNG·JPG·웹)을 확인한다.
2. PDF는 아래 스크립트로 페이지별 텍스트를 추출한다. 스크립트는 페이지마다 글자 수를 세고, 글자가 적은 페이지(기본 600자 미만)는 PNG로 렌더링한다. 캡처형 PDF(유튜브 화면, 슬라이드 캡처)는 텍스트만 보면 내용을 놓치기 때문이다.

```bash
bash .claude/skills/context-analysis/scripts/extract_pdf.sh "<PDF 경로>" "{WS}/00_extract/<자료번호>"
```

출력: `<outdir>/page_NN.txt`, 글자가 적은 페이지의 `page_NN.png`, `summary.tsv`(페이지·글자 수·이미지 여부).

3. `summary.tsv`를 보고 텍스트 페이지는 Read로, 이미지 페이지는 PNG를 Read로 직접 본다. 텍스트가 충분해도 표·그래프가 있는 페이지는 이미지로 한 번 더 확인한다. 표의 행·열이 텍스트 추출에서 뒤섞이는 일이 잦기 때문이다.
4. PNG·JPG 원본(마인드맵 등)은 Read로 직접 보고, 노드 구조를 계층 목록으로 옮긴다.

## 2. 팩트 카드 작성

원문에서 사업계획서에 쓸 수 있는 사실을 모두 카드로 만든다. 목차의 어느 소목차에 쓸지 모르는 사실도 일단 기록한다. 버린 사실은 집필가가 되살릴 수 없기 때문이다.

| 필드 | 작성 기준 |
|------|----------|
| ID | `{접두어}-{두 자리 번호}` (예: `MKT-07`). 실행 중에 바꾸지 않는다 |
| 내용 | 원문 의미를 바꾸지 않은 한 문장. 원문 인용이 중요하면 따옴표로 |
| 수치·단위 | 숫자 + 단위 + 통화 (예: `3조 2,000억 원`, `160억 달러`) |
| 기준 | 연도·기간, 지역(국내/글로벌/북미 등), 대상(애슬레저/스포츠웨어 전체 등) |
| 출처 위치 | 파일명 약칭 + 페이지 (예: `(4.4) p.3`) |
| 원출처 | 자료 안에서 인용한 기관·보고서·연도. 없으면 `없음` |
| 등급 | 아래 신뢰도 등급 |
| 활용 목차 | 목차 번호 (예: `2.2.1`, `2.3.1`) |

### 신뢰도 등급

| 등급 | 의미 | 예 | 사업계획서에서 쓰는 법 |
|------|------|----|---------------------|
| A | 정부·공공기관 통계, 공식 공고 | 통계청, 중소벤처기업부 공고, 관세청 | 그대로 인용 |
| B | 학술 논문, 업계 협회·전문 연구소 | 등재 학술지, 섬유산업연합회, 패션연구소 | 그대로 인용 |
| C | 언론 보도, 기업 공시·IR, 시장조사 기관 요약 | 신문 기사, DART 공시 | 인용 + 연도 명시 |
| D | AI 도구가 만든 리서치·요약 보고서 | ChatGPT, Genspark, STORM, Perplexity 산출물 | 원출처가 있으면 원출처로 인용하고 `[확인 필요: 원출처 대조]`, 없으면 방향성 근거로만 |
| E | 영상 리뷰, 개인 의견, 출처 미상 데이터 | 유튜브 리뷰, 블로그, 출처 없는 CSV | 정성 근거·고객 인식 사례로만 |

AI 보고서는 그럴듯한 수치를 출처 없이 만들어 내는 경우가 있다. 등급을 D로 두는 이유는 수치를 버리기 위해서가 아니라 집필가와 팩트체커가 원출처를 확인하도록 표시하기 위해서다.

## 3. 충돌·공백·주의 사항

- **충돌 표**: 같은 지표(예: 국내 애슬레저 시장 규모 2023년)가 자료마다 다르면 모든 값을 출처와 함께 나란히 적는다. 어느 값이 맞는지 판단하지 않는다. 판단은 집필가가 등급을 보고 한다.
- **단위·범위 주의**: 같은 "시장 규모"라도 글로벌/국내, 애슬레저/스포츠웨어 전체/레깅스 단일 품목, 출고가/소매가 기준이 다르다. 기준이 다르면 충돌이 아니라 "범위 차이"로 분류하고 그 차이를 적는다.
- **공백 목록**: 사업계획서 목차가 요구하지만 자료에 없는 정보를 적는다. 예: 시험성적서, 원가표, 인터뷰 결과, 팀 이력, MOQ·리드타임. 집필가가 `[창업자 입력 필요]`로 처리할 목록이 된다.

## 4. 웹 조사를 배정받았을 때

- 공식 출처만 쓴다: 정부·공공기관(k-startup.go.kr, mss.go.kr, 통계청 KOSIS 등), 협회·연구기관, 시험·인증기관 공식 페이지, 기업 공시.
- 정부지원사업 공고는 **해당 연도** 공고문을 찾는다. 지원 한도, 협약기간, 정부지원사업비·자부담 비율, 사업비 비목, 평가 항목, 블라인드 규정, 제출 분량은 해마다 바뀌기 때문이다. 찾은 연도와 찾지 못한 항목을 분명히 적는다.
- 각 카드에 URL과 확인 날짜를 적는다. 검색 결과 요약만 보고 쓰지 말고 원문 페이지를 열어 확인한다.

## 5. 팩트 시트 형식

`{WS}/01_analyst-{그룹}_facts.md`를 아래 순서로 쓴다.

```markdown
# 팩트 시트 — {그룹명} (실행 v{N})

## 0. 분석 자료
| 자료 | 형식·분량 | 판독 방식 | 판독 불가 구간 |

## 1. 핵심 요약 (집필가용 5~8줄)

## 2. 팩트 카드
| ID | 내용 | 수치·단위 | 기준 | 출처 위치 | 원출처 | 등급 | 활용 목차 |

## 3. 충돌·범위 차이
| 지표 | 값 A (출처·등급) | 값 B (출처·등급) | 차이 원인 추정 |

## 4. 공백 목록 (자료에 없는 목차 요구 정보)

## 5. 분석 메모 (해석·시사점 — 사실과 분리)
```

## 6. 점검표

- [ ] 배정받은 모든 파일, 모든 페이지를 읽었다(이미지 페이지 포함)
- [ ] 모든 수치에 단위·기준·출처 위치가 있다
- [ ] AI 생성 보고서 수치에 D등급과 원출처 여부를 적었다
- [ ] 충돌과 범위 차이를 구분했다
- [ ] 해석은 분석 메모로 분리했다
