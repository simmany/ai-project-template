# 데이터 파일 분석 → 사업계획서용 차트

데이터 차트는 사업계획서에서 가장 강한 근거가 될 수도, 가장 쉽게 공격받는 약점이 될 수도 있다. 이 스킬은 데이터에서 쓸 수 있는 메시지와 그 한계를 함께 밝히고, 차트 한 장에 메시지 하나를 담는다.

## 1. 시작 전에 읽을 것

1. `dataviz` 스킬을 불러와 차트 형태 선택·마크·색 원칙을 익힌다. 색은 그 스킬의 기본 팔레트 대신 `.claude/skills/bizplan-orchestrator/references/visual-system.md`의 프로젝트 팔레트를 쓴다(다른 그림과 한 문서처럼 보이게 하기 위해서다).
2. `custom-instruction/사업계획서 목차.txt`를 읽고 차트가 들어갈 만한 소목차(시장 규모, 경쟁 현황, 타깃 고객 등)를 확인한다.

## 2. 데이터 프로필

- 인코딩: UTF-8 BOM(`utf-8-sig`)을 먼저 시도하고, 실패하면 `cp949`.
- 한 파일에 `### 제목` 같은 구분 줄로 여러 표가 이어져 있으면 블록별로 분리해 각각 데이터프레임으로 만든다. 그대로 `read_csv`하면 열이 틀어진다.
- 블록마다 행 수, 열, 단위, 기간, 결측을 표로 정리한다.

## 3. 신뢰도 점검

아래 신호가 있으면 인사이트 파일의 "신뢰도 메모"에 근거와 함께 적는다. 데이터를 버리라는 뜻이 아니라, 집필가가 캡션과 본문에서 한계를 밝히게 하려는 것이다.

| 신호 | 확인 방법 |
|------|----------|
| 출처 미기재 | 파일·열·주석에 기관명이 없음 |
| 합성·예시 데이터 의심 | 값이 모두 5·10 단위로 둥글다, 증가 폭이 지나치게 규칙적이다, 점유율 합계가 정확히 100이다 |
| 범위 불일치 | 다른 자료(팩트 시트)의 같은 지표와 규모가 다르다(예: 국내 시장이라면서 글로벌 규모 수준) |
| 단위 모호 | "판매량 (억 달러)"처럼 판매량과 금액이 섞인 표기 |
| 표본 크기 | 집단별 n이 작으면(예: 30 미만) 평균 차이를 단정하지 않는다 |

## 4. 분석

- 성장 지표: CAGR = (끝값/시작값)^(1/연수) − 1. 계산식과 구간을 함께 적는다.
- 비교 지표: 집단·브랜드별 평균 차이, 순위, 격차. 점수형 데이터는 척도(예: 1~5점)를 밝힌다.
- 파생 지표를 만들면 "파생"이라고 표시하고 계산식을 남긴다(예: 가성비 지수 = 성능 점수 − 가격 점수).
- 사업계획서 주장으로 연결한다: "그래서 우리 타깃·포지션에 무엇을 뜻하는가"를 인사이트마다 한 줄로 적는다. 단, 데이터가 말하지 않는 결론은 쓰지 않는다.

## 5. 차트 제작

공통 스타일 모듈을 쓴다. 한글 글꼴·팔레트·출처 표기·덮어쓰기 방지를 한곳에서 처리한다.

실행: `uv run --with matplotlib --with pandas python {WS}/01_data-analyst_charts.py`

차트 규칙:
- **제목은 결론 문장**이다("연도별 시장 규모"가 아니라 "시장 규모 6년간 3.2배"). 평가위원은 제목만 읽고 넘어가는 경우가 많다.
- 우리 타깃·우리 포지션과 관련된 요소 하나만 ACCENT, 나머지는 PRIMARY/NEUTRAL.
- 예측값은 실적값과 구분한다(점선 또는 옅은 색 + "전망" 레이블).
- 3D, 파이 차트 남용, 이중 축은 피한다. 비중 비교는 가로 막대가 더 정확히 읽힌다.
- 크기 8×4.5인치(본문 폭), 200dpi. 출처는 차트 아래 왼쪽.
- 만든 뒤 PNG를 Read로 직접 보고 글자 깨짐·겹침·잘림을 확인한다.

```markdown
# 데이터 인사이트 (실행 v{N})
```
