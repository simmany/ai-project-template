# 창업자 입력 요청 목록 (실행 v1, 초안 r0 기준)

작성: bizplan-writer / 작성 기준일 2026-10-22
초안 `02_writer_draft_r0.md`에서 `[창업자 입력 필요]`로 비워 둔 칸과 `[가정]`으로 집필가가 임시 결정한 값을 창업자가 채우거나 확정해야 한다. 우선순위는 "없으면 서류 평가에서 바로 감점되는 것"부터 매겼다.

## 우선순위 기준
- **P1**: 평가 항목 핵심 근거. 없으면 해당 소목차가 '계획'만 남아 실현 가능성·팀 점수가 낮아짐. 제출 전 반드시 필요
- **P2**: 수치 정확도·사업비 적정성에 직결. 가정값을 실측으로 바꿔야 함
- **P3**: 있으면 설득력이 오르지만 없어도 제출 가능
