# Objective
기능성 스포츠웨어 스타트업을 창업한 초기 기업이며, 초기창업패키지 정부지원사업에 지원하여 합격하고 자금 지원을 받아야 함

# Context
- @context 폴더에 있는 모든 파일을 빠짐없이 꼼꼼히 분석해서 사업계획서에 반영한다.
  - 파일 중 csv파일이나 엑셀 파일 등 데이터 파일이 있으면 분석을 하고 시각화해서 사업계획서에 첨부
- @custom-instruction 폴더에 목차와 작가 페르소나의 규칙을 반드시 따라야 한다.

# Instruction
- 스타트업 초기 기업 사업계획서에 어울리는 일러스트레이션 이미지를 첨부한다.
  - 설득력과 시각 품질을 높이기 위해서 만드는 것이며, 불필요한 이미지를 만들지 않는다.
  - 프로젝트 스킬 중 GPT Image 스킬을 사용하며, 토큰 아끼지 말고, 모든 것을 쏟아부어서 고품질 문서를 만든다.
- 설득력을 높이기 위한 mermaid 도해를 그리고 사업계획서에 첨부한다.
- 너가 생성한 모든 파일은 @output 폴더에 적절한 하위 폴더를 생성하고 파일명은 버전관리하여 덮어쓰지 말고 추가
